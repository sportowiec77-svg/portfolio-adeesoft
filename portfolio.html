Strona internetowa dla kosmetologa

03 / Fitness · FORMA Fitness&Gym

Strona internetowa dla klubu fitness w Mikołowie

Projekt strony WWW przygotowany dla FORMA Fitness&Gym w Mikołowie. Serwis został wykonany w oparciu o CMS Joomla oraz dopracowany za pomocą CSS i JavaScript, z wykorzystaniem własnej grafiki dostarczonej przez klienta. Układ porządkuje ofertę, grafik zajęć i najważniejsze informacje, ułatwiając użytkownikom szybkie dotarcie do interesujących ich treści.

Zobacz projekt: FORMA Fitness&Gym

04 / Gastronomia · Pizzeria Viva

Strona internetowa dla Pizzerii Viva

Projekt strony WWW dla restauracji Pizzeria Viva został przygotowany wspólnie z klientem, z wykorzystaniem dostarczonych przez niego zdjęć potraw, wnętrza i materiałów wizualnych. WordPress, Elementor oraz dodatkowy CSS i JavaScript pozwoliły połączyć łatwą edycję treści z indywidualnym wyglądem i czytelną prezentacją menu, galerii oraz najważniejszych informacji.

Zobacz projekt: Pizzeria Viva

WordPress · Elementor · CSS · JavaScript
